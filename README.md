# Tier 7 Madness (TAUR Edition).
A successor of the original Tier 7 Madness mod by X-Core. Made by/for the TAUR community.

Join our discord server - https://discord.gg/tMVEffyXpD
## Introduction:
Tier 7 Madness (T7M for short) is a mod based on 45rfew's Rumble. Just like it's prototype, the main objective is to get as much kills for your team as possible, but from here on, the mod adds a bunch of new features that change the gameplay dynamic. Tons of balanced and unique ships, custom maps of high quality, and a lot of QoL features to make sure the experience is enjoyable enough to become actually replayable. Being a community-driven mod, it's getting constantly updated based on given feedback and suggestions, using assets made by a lot of different creators to give potential and popularize their work without any negative intentions, as the main goal of the mod's creator will always be having fun and sharing that fun with others.
